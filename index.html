Export & Publish (Required for QR)

Public QR verification only works after you export and upload to Vercel

⚠️ Why QR scans fail for visitors

Certificates saved in Admin are stored in this browser only (localStorage). When someone scans a QR code they open certificateunifiedmentor1617.vercel.app, which does not have your browser data. You must Export → Upload to Vercel after every new certificate so the public site includes it.

Steps:
1. Generate / add all certificates in Admin
2. Click the button below to download index.html
3. Upload that file to your Vercel project (replace existing index.html)
4. Wait for deploy · then test QR: /?verify=UMID…
